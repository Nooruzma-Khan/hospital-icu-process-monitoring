CO3CPU scheduling: Priority vs Round Robin

Uses the patients from the process table. Priority (non-preemptive) serves critical patients first; Round Robin gives routine checks a fair share of the CPU.

CO3Sensor deadlock avoidance: Banker’s algorithm

Shared sensors: ECG monitors (E), Ventilators (V), Infusion pumps (I). Edit any number, then check whether the allocation is safe. Test a new request before granting it.

CO4Memory management

A. Memory allocation to RAM partitions (fixed partitions)

Each patient monitor’s memory request is placed in a free RAM partition. Wasted space inside a partition is internal fragmentation.

B. Page replacement for the patient-data buffer

The reference string is the sequence of data pages the monitoring screens need. Compare FIFO and LRU.

CO5Patient vitals: indexed file allocation

Each patient’s vitals record is a file. One index block holds pointers (max 8) to scattered data blocks, one block per vitals reading. Retrieve a patient’s vitals log by Patient ID.
